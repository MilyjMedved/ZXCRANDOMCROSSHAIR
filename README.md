# ZXCRANDOMCROSSHAIR
Программа для рандомного прицела при каждом заходе в игру 
https://github.com/ReDegenerator/WTRandomaizer оригинальная программа спасибо человеку за идею я взял его основу и дописал программу изменил что добавления танков в программу осуществляется в файл tanks.txt а не чтоб перезаписывать программу прицелы будут рандомиться после закрытия игры сразу очень быстро и без повторок на танки 
Буду дальше обновлять программу добавление танков сразу в текстовой фаил по мере добавления пишите которые я не добавил 




Инструкция по установке 
1-Поместите файлы в папку н рабочем столе
2-Запустите exe файл и нажмите кнопку 1
он найдет папку с прицелами на компьютере и создаст txt файл с директорией и зарандомит прицеллы
3-Чтоб каждый раз при заходе были рандомные прицелы нажмите кнопку 2 и перезапустите компьютер 




Важно прицелы кидайте UserSights\all_tanks чтоб нечего не сломалось по идее она ищет во всей папке UserSights ну чтоб наверняка
